# 🌱 EcoFusion - Smart Waste Management System

## 📌 Project Overview

EcoFusion is a Smart Waste Management Dashboard developed using HTML, CSS and JavaScript.

The project demonstrates how technology can be used to monitor waste levels, encourage waste segregation and support sustainable waste management.

The system provides a user-friendly dashboard for monitoring biodegradable and non-biodegradable waste.

---

## 🎯 Objectives

- Monitor waste levels digitally.
- Separate biodegradable and non-biodegradable waste.
- Support recycling of plastic waste.
- Support conversion of organic waste into fertilizer.
- Provide a simple and responsive dashboard.
- Promote environmentally friendly waste management.

---

## 🚀 Features

### 🗑️ Smart Waste Monitoring

Displays the current waste level of different bins.

### 🌱 Organic Waste

The biodegradable waste section represents organic waste that can be processed into natural fertilizer.

### ♻️ Plastic Recycling

The non-biodegradable section represents recyclable materials such as plastic.

### 📊 Dashboard

The dashboard displays:

- Total waste collected
- Recyclable waste
- Organic waste
- Eco efficiency
- Bin capacity
- Current waste level

### 🌙 Dark Mode

Users can switch between light and dark themes.

### 📱 Responsive Design

The website works on:

- Desktop
- Laptop
- Tablet
- Mobile

### 🎮 Interactive Demo

Users can simulate:

- Adding organic waste
- Adding plastic waste
- Emptying bins
